Why A++

Built for humans first.

Every design decision prioritises readability and forgiveness over strictness.

🗣️
Plain English Syntax
Write set x to 10 or if x is greater than 5 then: — no brackets, no semicolons, no confusion.
🧠
IECE — Smart Autocorrect
The Intelligent Error Correction Engine fixes typos, inserts missing keywords, and learns your patterns permanently.
↔️
English & Symbol Operators
Every operator works both ways. is greater than and > are identical. Mix them freely.
📊
Built-in Statistics
mean of scores, median of data, random integer between 1 and 100 — all built in, no imports.
🔗
Function Chaining
Chain operations with dots: set age to input. trim. convert to int. — left to right, readable as prose.
🐍
Python Transpiler
Every A++ statement compiles to clean Python under the hood — full performance, full ecosystem access.
🔒
Error Handling
Natural try / catch err / finally / end try blocks. Assertions with check x > 0 or fail "message".
🔍
Step Debugger
Built-in step-through debugger. Set breakpoints with bp 12, inspect variables live, step line by line.

IECE v3

The language that corrects itself.

The Intelligent Error Correction Engine catches mistakes before they crash — and remembers them forever.

A++ REPL — IECE in action
A++[1]> sett x too 10
💡 Typo-fix: 'sett' → 'set', 'too' → 'to'
 
A++[2]> repeaat 5
💬 Did you mean: 'repeat 5 times'? [Y/n]: y
 
A++[3]> set x to sqaure root of 144
💡 Fuzzy-correct: sqaure → square
12.0
 
A++[4]> increase scor by 5
⚠️ Variable 'scor' not defined.
💡 Did you mean 'score'?
Correct 'scor' → 'score'? [Y/n]: y
 
A++[5]> endif
💡 Keyword-insert: 'endif' → 'end of if-else'
  • 🔤
    Fuzzy Keyword CorrectionDetects and fixes misspelled keywords using difflib similarity matching at 0.88 precision threshold.
  • 🔑
    Missing Keyword Insertionset x 10 → set x to 10. Detects and fills structural gaps automatically.
  • 🔄
    Word-Order TranspositionCatches swapped words: x set to 10 → set x to 10.
  • 🧠
    SQLite Learning MemoryEvery accepted correction is stored with a confidence score. High-confidence fixes apply silently next session.
  • 📚
    Three IECE Modesmode auto — silent. mode learn — explains everything. mode standard — balanced.
  • 📍
    Pointer Error DisplayShows ^ under the exact character that caused the issue, with up to 3 correction suggestions.

Get Started

Run in 30 seconds.

Python 3.10+ required. No pip packages needed — pure standard library.

$git clone https://github.com/anandathirtha2009-art/aplus-language.git
$cd aplus-language && python3 aplus.py
That's it. The REPL starts immediately.
$python3 aplus.py
Interactive REPL with line numbers, tab indentation, and IECE correction.
$python3 aplus.py myprogram.aplus
Run any .aplus file directly. Add --debug for full tracebacks.
