Why A++

Built for humans first.

Every design decision prioritises readability and forgiveness over strictness.

🗣️
Plain English Syntax
Write set x to 10 or if x is greater than 5 then:
🧠
IECE — Smart Autocorrect
Fixes typos, inserts missing keywords, learns your patterns.
↔️
English & Symbol Operators
is greater than and > are identical.
📊
Built-in Statistics
mean of scores, median of data, random integer between 1 and 100
🔗
Function Chaining
Chain operations with dots: set age to input. trim. convert to int.
🐍
Python Transpiler
Every A++ statement compiles to clean Python.

IECE v3

The language that corrects itself.

A++ REPL — IECE in action
A++[1]> sett x too 10
💡 Typo-fix: 'sett' → 'set', 'too' → 'to'
A++[2]> repeaat 5
💬 Did you mean: 'repeat 5 times'? [Y/n]: y
  • 🔤 Fuzzy Keyword Correction – difflib similarity
  • 🔑 Missing Keyword Insertion – set x 10 → set x to 10
  • 🧠 SQLite Learning Memory – confidence scores, decay
  • 📚 Three IECE Modes – auto, learn, standard
